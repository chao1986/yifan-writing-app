# 一凡文库

一款本地优先的中文作文批改应用。作文、修改记录和定稿以 Markdown/JSON 文件保存在自己的电脑中。读写作文和调用大模型由 Tauri 的 Rust 后端完成；测试阶段的 API Key 与其他模型配置一起保存在本机 `settings.json`，不写入作文文件。

## 主要功能

- 输入作文题目、要求和正文，随时保存草稿
- 调用 OpenAI 兼容接口生成逐条、可直接替换的修改建议
- 在原文中标记建议，逐条接受或忽略；正文也可直接编辑
- 选中一句或一段直接向 AI 提出局部修改要求，局部操作留在当前版本内，不占用正式版本号
- 每次 AI 批改生成一个新版本，保留历次草稿与批改记录
- 点击版本列表只读查看任意正式版本；历史版本可恢复为新的当前版本，不覆盖原记录
- 持续记录原稿、AI 建议、接受或忽略结果以及人工修改，并将完整历程作为下一次批改的上下文
- 每篇作文都可从文库打开“对话记录”，查看真实发送给模型的 System/User 消息、模型原始回复、接口、模型、作文版本和失败信息
- 预览修改后的正文，满意后定稿
- 按题目、写作要求或正文关键词搜索本地作文
- 自定义模型服务、模型名称、API Key、提示词和文库目录
- 在设置中切换白天或黑夜界面，选择会保存在本机

## 本地开发

需要 Node.js、Rust，以及 macOS/Windows/Linux 对应的 Tauri 系统依赖。

```bash
npm install
npm run tauri dev
```

这会打开开发窗口。界面改动会立即刷新；Rust 后端改动会重新编译并重启窗口，不需要重新打包。安装包用 `npm run tauri build` 生成。

构建安装包：

```bash
npm run tauri build
```

## 首次使用

1. 打开“设置”。
2. 填写服务商名称、OpenAI 兼容 API 地址、模型名称和 API Key。
3. 选择本地文库目录，保存设置后测试连接。
4. 新建作文，保存草稿或直接开始 AI 批改。

默认接口地址为 `https://api.openai.com/v1`。应用会请求该地址下的 `/chat/completions`；其他服务需要提供兼容格式。

## 文件结构

每篇作文使用一个独立目录：

```text
一凡文库/
└── essay-xxxxxxxxxxxx/
    ├── metadata.json
    ├── prompt.md
    ├── history.json
    ├── conversations.jsonl
    ├── draft-01.md
    ├── review-02.json
    ├── draft-02.md
    └── final.md
```

作文内容和历史版本均可直接复制、备份或用普通文本编辑器打开。正式版本保存在 `draft-XX.md`；局部 AI 要求、AI 返回内容、接受或忽略结果保存在 `history.json`，因此不会造成版本数量膨胀。使用 AI 批改或局部修改时，当前题目、写作要求、本篇批改提示词、当前正文和此前完整修改历程会发送给所配置的模型服务商。

真实模型请求记录分别保存在每篇作文目录的 `conversations.jsonl`，每篇最多保留最近 50 次，并显示在文库的“对话记录”中。可以删除单条记录或清空本篇记录；这些操作不会影响作文版本和 `history.json` 中用于后续批改的修改历程。记录包含实际提示词和模型回复，但不会记录 API Key。旧版全局 `model-conversations.json` 会在首次读取时自动迁移到对应作文目录。
